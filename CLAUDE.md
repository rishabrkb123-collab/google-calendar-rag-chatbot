# Project: Agentic Chatbot — Google Calendar + RAG

## Overview
An agentic chatbot that connects to a user's Google Calendar, lists all events, and provides search/filter capabilities. The UI is animated, dynamic, and interactive. A RAG (Retrieval-Augmented Generation) layer will power natural language queries over calendar data.

## Project Goals
- OAuth2 authentication with Google Calendar API
- Fetch and display all calendar events
- Search and filter events (by date, title, calendar, etc.)
- Animated, dynamic, interactive UI
- RAG model for natural language event querying
